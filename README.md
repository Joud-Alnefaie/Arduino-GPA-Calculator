## What started as a Logic Design course project requiring a simple light circuit with a logic gate, turned into a grander and more complex circuit. This is a hardware GPA calculator and grade classifier featuring menus that guide the user into either calculating the GPA of several courses or classifying a grade based on a given score. A keypad was used for input, an LCD screen for output, and a potentiometer for power control, all connected through an OR logic gate.

### Libraries Used
- Adafruit LCD library
- Keypad library by Mark Stanley & Alexander Brevig

### Components
- Arduino Uno R3
- 16x2 LCD screen
- Keypad
- Potentiometer
- OR logic gate
