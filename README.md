## Arduino GPA Calculator

### This is a hardware GPA calculator and a grade classifier. It has simple menus such as a main menu that then (based on the user\'s choice) goes into each task\'s menu, then either calculate the GPA of several courses or, outputs a grade based on the score given. A keypad was used for input, and an LCD screen was used for output, then a potentiometer for power control, all connected together through an OR logic gate.

### I used 2 libraries which are the Adafruit LCD, and the keypad library by Mark Stanley & Alexander Brevig.

### The following components were utilized: Arduino Uno R3, 16x2 LCD screen, keypad, potentiometer, OR logic gate.
